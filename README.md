# Zad Furniture - E-commerce Platform 🪑

Zad Furniture is a robust, production-ready e-commerce backend built with **Laravel**. It is specifically designed for furniture retail, handling complex product attributes, hierarchical categories, and a seamless shopping experience.

## 🚀 Key Features

- **Advanced Product Management:** Handles complex furniture attributes (material, dimensions, color) using Eloquent ORM.
- **Hierarchical Categorization:** Organized product structure with multi-level categories.
- **Secure Authentication:** Multi-guard authentication system for users and administrators.
- **Shopping Cart System:** Fully functional cart with real-time updates and persistent storage.
- **Order Management:** Complete workflow from order placement to status tracking.
- **Optimized Performance:** Efficient database design with indexed queries and Eloquent relationships (One-to-Many, Many-to-Many).

## 🛠️ Tech Stack

- **Framework:** [Laravel 10+](https://laravel.com/)
- **Language:** PHP 8.1+
- **Database:** MySQL
- **Frontend Integration:** Blade Templates / RESTful APIs
- **Tools:** Git, Composer, Artisan

## 📁 Project Structure Highlights

- **Models:** Optimized Eloquent models with defined relationships and accessors.
- **Controllers:** Clean logic separation using Resource Controllers.
- **Migrations:** Structured database schema with foreign key constraints for data integrity.
- **Middleware:** Custom middleware for role-based access control (RBAC).
